# Demo videos

Drop `.mp4` / `.avi` / `.mov` / `.mkv` / `.webm` clips here. Each one appears as a
one-click button in the DRISHTI dashboard ("DEMO FEEDS"), which registers a
file-source camera and starts it.

Suggested set for a full run-through:

| File | Shows |
|------|-------|
| `vehicle_perimeter.mp4` | detection + tracking + tripwire intrusion |
| `fight_*.mp4` | FIGHT alert (two people in sustained contact) |
| `fire_*.mp4` | FIRE / SMOKE alert |

Clips loop forever, so a single short file is enough for a demo. Deleting a demo
camera from the UI removes the camera row but keeps the file on disk.
